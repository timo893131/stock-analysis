# 公開免設定模式

一般使用者只需開啟網站，首頁按「一鍵 AI 重點整理」，或到找股票搜尋上市、上櫃及 ETF，再載入分析與虛擬練習。不需要網站存取碼或手動填 Worker 網址。

## 管理者部署

既有 GitHub Secrets 保留 `CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`、`FINMIND_TOKEN`、`GEMINI_API_KEY`。`STOCKROOM_ACCESS_KEY` 不再使用；不用將任何金鑰放到公開網頁。Cloudflare Token 需能部署 Workers 與 SQLite Durable Objects。

修改 `cloudflare/**` 或 `.github/workflows/deploy-api.yml` 後會自動部署；也可手動執行 `Deploy free Taiwan research API`。部署完成以官方 Action 的 `deployment-url` 輸出生成 `service-config` 分支的 `api.json`，僅包含公開網址、模式與驗證結果，沒有金鑰。網站自動取得這份設定；GitHub raw 快取傳播可能短暫延遲。

部署流程使用 `/brief` 的唯讀檢查驗證已存在的摘要快取，不消耗模型額度。驗證失敗仍發布連線設定，`briefCheck.status` 顯示 unavailable，不會把失敗當成功。

## 資料與額度

- 公開訪客共用每 UTC 日 120 次 FinMind、10 次 Gemini，前置持久計數、失敗計次，沒有自動重試。原有 GitHub 排程用量另外計算。
- 行情與按需財報快取 6 小時；同資料 AI 重用至 24 小時。不同股票的相同請求會共用結果；摘要依研究清單的行情內容比對，資料更新後才重新生成。
- 摘要目前分析每日研究清單（20 檔）的收盤價、漲跌及 MA20/MA60。會列出實際涵蓋股票；不是整個台股市場或即時新聞的分析。
- 完整名錄提供搜尋，個股按需取得至少 60 日歷史。無法保證歷史名錄、停牌或新上市股票都有足夠資料。財報按需版先提供營收、EPS、營業現金流，其他指標標示未提供；ETF／金融業不套一般企業比率。
- 訪客不需登入；Origin 檢查不等於身份驗證。公開服務可能被其他訪客耗用每日額度，到上限即停止。沒有開啟付費升級或付費模型回退。
- 虛擬交易依之後第一筆日收盤結算；股票稅 0.3%、股票型 ETF 0.1%。B 結尾債券 ETF 模型到 2026 年底免稅，之後暫用 0.1%，需依法規持續更新。未處理股利拆股，不涉及真實券商下單。

若新摘要的模型請求失敗，服務會讀取本站已發布的 AI 個股報告，只保留與目前行情日期相符、生成未超過七天的報告，標示 `mode: published` 與原始生成時間。這是原文閱讀備援，不是假裝重新生成的綜合摘要；備援快取一小時，沒有額外模型重試。沒有合格報告時才顯示不可用。

健康檢查改用 `/brief` 的 `readOnly: true`，只檢查快取，不再觸發模型生成或消耗 AI 次數。GitHub 行情發布會重用相同資料指紋的 24 小時內解讀；生成失敗時保留行情時間相同的有效舊解讀與原始生成時間，避免把可用報告覆寫成空白。
