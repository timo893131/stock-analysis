# 新手手機版與自由虛擬投資驗證（2026-11-12）

這次使用原有設計系統，新增手機優先入口並清楚區別手動金額、AI 參考比例和兩種虛擬成交方式。沒有更換行情來源或增加共用免費服務限額。

## 功能結果

- 首頁從全市場價量初選列 3 檔預覽，保留完整候選與官方來源日期。AI 狀態僅來自同行情日的實際個股報告，不把全市場摘要套成各股推薦。
- 手動輸入金額使用完整預算換算整數股，列出費用和零頭；移除固定 10% 部位及首筆 30% 縮減。
- 快速練習使用已取得收盤與滑價，確認後更新本機持倉；練習時間與價格來源日分別記錄。不是盤中行情、真實成交或回測。
- 原 v2 帳戶與舊委託保留。新增 funding 只記不足時補入的虛擬本金；累計淨盈虧扣除全部投入，取消／未成交釋放預留，追加資金不會冒充收益。
- AI action + allocationPct 是模型實際回覆（adviceVersion 3）；沒有比例就明說，不用公式文字假冒。比例只是研究建議，不限制自由練習。預算只在本機換算。

## 測試

- 74 項 Node + 34 項 Python 測試通過。
- 8 組 Playwright 流程通過：interface、full-market、market-quick、journal、paper-settlement、planner、free-practice、app-shell。
- 新流程在 360 / 390 / 1280 寬度驗證：測試價格 745 元、預算 30,000 元可買 40 股（含費用與滑價），模型回覆 10% 時另列約 4 股參考；兩者不互相覆寫。
- 200 萬以上虛擬買入可自動補本金，持倉與現金正確；賣出不重設投入，追加不算獲利，舊的下一交易日委託不被強制成交。
- 一鍵 AI 缺報告時只送出一個 symbol/ai 請求，有有效報告時重用；沒有把金額傳給 API。
- 實際 service worker 的離線阻擋與更新後資料保存回歸通過。
